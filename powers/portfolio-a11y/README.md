# portfolio-a11y — Kiro power

Kiro power đóng gói quy ước **accessibility (WCAG AA)** và Tailwind cho web profile cá nhân
single-page bằng React. Bundle gồm một Agent Skill hướng dẫn dựng và review các section
(Hero, About, Skills, Projects, Contact, Footer) sao cho tiếp cận được.

## Nội dung
```
portfolio-a11y/
├─ plugin.json                     # manifest nhận diện power
└─ skills/
   └─ a11y-portfolio/
      └─ SKILL.md                  # quy tắc a11y + ví dụ code
```

## Cách chia sẻ / cài đặt
Power có thể chia sẻ dưới dạng repository GitHub public, không cần phê duyệt để publish:

1. Đẩy thư mục này lên một repo GitHub public (ví dụ `your-name/portfolio-a11y`).
2. Trong Kiro, thêm power từ URL repo qua giao diện Powers.
3. Skill `a11y-portfolio` sẽ được nạp theo từ khoá (accessibility, wcag, tailwind, portfolio...).

Có thể (tuỳ chọn) gửi power để xét đưa vào Kiro powers registry chính thức.
